## Supabase (база сайта artshpace.kz)
Supabase → SQL Editor → новая вкладка → вставить файл целиком → Run. Строго по порядку:

- [ ] `supabase/migrations/0032_game_progress.sql` — сохранение игрового прогресса учеников (опыт, курсы, награды) в базе.
- [ ] `supabase/migrations/0033_online_courses.sql` — онлайн-курсы: каталог, уроки, коды доступа, записи на курс, награды курса, фото учеников (bucket `avatars`), колонка `profiles.avatar_url`.

Проверка после 0033: в приложении войти аккаунтом admin/director → «Обучение» → «Редактор курсов» → должен открыться список курсов без ошибки.
