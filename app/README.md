# Art Space — мобильное приложение студии

Android-приложение (позже и iPhone) для Shpigotskiy Art Space. Сделано на Expo / React Native,
в стиле сайта. Работает с той же базой (Supabase), что сайт **artshpace.kz** (ветка
`claude/shpigotskiy-art-space-site-2uwim5`): тот же аккаунт и тот же журнал педагога.

## Что умеет

**Как сайт:**
- главная, направления (описание, педагоги, цена), расписание групп, прайс;
- запись на бесплатное пробное: заявка уходит в WhatsApp студии (или на сервер, см. ниже),
  потом экран «Что дальше»: карта 2ГИС, добавление в календарь;
- педагоги, галерея «Выступления и работы», о студии и контакты, FAQ, публичная оферта;
- онлайн-курсы: заявка на курс и вход в курс по коду доступа (демо-код `DEMO`).

**Новое:**
- **Обучение:** уроки открываются по очереди: видео YouTube, теория, домашнее задание с отчётом
  ученика и кнопкой «Отправить педагогу в WhatsApp»;
- **Прогресс:** баллы, 5 уровней (Новичок → Мастер), серия дней подряд, история занятий;
- **Награды:** 10 значков, выдаются автоматически, с поздравлением на экране;
- **Профиль ученика:** имя и телефон подставляются в заявки;
- **Кабинет студии (вход как на сайте, по email или ФИО):** посещаемость из журнала, навыки
  (уровни 0–5 из «Карты навыков»), оценки и комментарии педагогов. Родитель видит своих детей
  (`student_guardians`), ученик видит себя (`students.user_id`). За посещения начисляются баллы
  и отдельные награды;
- **С сайта в реальном времени:** «Достижения студии» (`studio_achievements`) и новые фото
  галереи из «Медиацентра» (`media_items`, раздел `gallery`).

Онлайн-курсы и их прогресс пока хранятся на телефоне: в базе сайта для них ещё нет таблиц.
Журнал и оценки педагоги ведут на сайте, приложение их только показывает.

## Где менять контент

| Что | Файл |
|---|---|
| Направления, педагоги, цены, расписание, FAQ, оферта, галерея | `src/data/content.ts` |
| Онлайн-курсы и уроки (`yt` — ID ролика YouTube) | `src/data/content.ts` → `COURSES` |
| Награды, баллы, уровни | `src/lib/progress.tsx` |
| Адрес сайта, ключи базы Supabase, сервер для заявок | `src/config.ts` |
| Вход и загрузка успеваемости | `src/lib/account.tsx` |
| Цвета и шрифты | `src/theme.ts` |

Фото и видео приложение берёт с сайта по тем же путям (`media/...`), что и `index.html`.
Если файла нет, показывается иконка. Фото, которые уже лежат в репозитории, вшиты в
приложение (`assets/media`).

## Как получить APK

Сборка идёт сама в GitHub Actions (`.github/workflows/android-apk.yml`) при каждом изменении
папки `app/`:
1. GitHub → репозиторий → **Releases** → «Art Space — Android (последняя сборка)» → `ArtSpace.apk`;
2. открыть файл на телефоне и разрешить установку из этого источника.

Сборка подписана отладочным ключом: так её можно ставить напрямую. Для Google Play
понадобится свой ключ подписи (сделаем при публикации).

## Разработка

```bash
cd app
npm ci
npx expo start        # запуск для разработки
npx tsc --noEmit      # проверка типов
```
